# ADR-0007 — moving average принимается только как механический baseline

## Статус

Принято для M0/S4 с запретом performance claims.

## Контекст

Moving average широко используется в учебных примерах, но подбор окон на коротком
ряду создаёт ложное доказательство. Проекту нужен первый понятный rule-based робот,
чтобы проверить общий контракт стратегии до сложных методов.

## Решение

Реализовать long/flat `BOT-RULE-101` в эталонном Python-движке. Окна передаются
явно, не оптимизируются, сигнал использует только доступные closes и исполняется на
следующем баре. Робот всегда запускается рядом с четырьмя контролями.

## Последствия

Получаем прозрачный baseline и тест временной причинности. Отрицательная сторона —
результат на modelled sample нельзя использовать даже как слабое доказательство
рыночной пользы; допуск потребует лицензированных данных и sealed OOS.
