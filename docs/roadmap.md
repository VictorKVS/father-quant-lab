# Roadmap

## M0 — Electronic Market History

- S0: repository and governance skeleton
- S1: dataset contract and provenance model
- S2: official daily FX data adapter
- S3: deterministic backtest engine
- S4: moving-average baseline
- S5: transaction-cost and risk model
- S6: regime comparison report
- S7: paper-trading simulator

## M1 — Economic events

Rates, inflation, employment, central-bank decisions, and publication revisions.

## M2 — Political and weather events

Evidence-based event cards, causal mechanisms, confidence levels, and counter-evidence.

## M3 — Crypto extension

BTC market data, 24/7 execution rules, exchange-specific costs, and liquidity regimes.
