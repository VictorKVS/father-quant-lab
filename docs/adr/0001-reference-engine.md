# ADR-0001: собственный минимальный эталонный движок

- Статус: accepted
- Дата: 2026-08-16

## Контекст

Внешние фреймворки имеют разные правила времени, fill, комиссии и округления. Если
сразу принять один из них за истину, расхождение результата будет трудно объяснить.

## Решение

Создать небольшой детерминированный event-driven движок без runtime-зависимостей.
Он служит эталоном для golden fixtures, а не заменой промышленной платформы.

## Последствия

- правила исполнения прозрачны и покрываются тестами;
- VectorBT, NautilusTrader и LEAN можно сравнивать с единым эталоном;
- сложные order book и partial-fill модели откладываются до отдельного ADR;
- live-торговля данным решением не разрешается.
