# ADR-0003: терминал отделён от торгового ядра

- Статус: accepted
- Дата: 2026-08-16

## Контекст

Профессиональный интерфейс может создать ложное ощущение готовности системы. Если
расчёты, стратегия и риск будут находиться в UI, их трудно независимо тестировать и
невозможно безопасно переиспользовать в replay, shadow и paper.

## Решение

Торговая консоль является клиентом типизированных Market Data, Strategy, Risk,
Execution, Portfolio, Evidence и Replay API. Источником состояния остаётся backend.
UI не хранит брокерские секреты, не рассчитывает окончательный P&L и не может обойти
Risk Guardian.

## Последствия

- ядро можно тестировать до создания интерфейса;
- web, desktop и read-only клиенты получают одинаковую истину;
- UI допускает красивую визуализацию без повышения maturity ядра;
- отказ интерфейса не отменяет risk limit и kill switch;
- Console MVP начинается после принятия M0 Control League.
