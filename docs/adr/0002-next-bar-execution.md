# ADR-0002: исполнение сигнала на следующем баре

- Статус: accepted
- Дата: 2026-08-16

## Контекст

Если стратегия использовала close бара N и была исполнена по тому же close без
доказанной возможности такой сделки, бэктест получает недоступную в реальности цену.

## Решение

Решение формируется после close N и исполняется по open N+1 с моделью spread,
slippage и commission. Принудительное закрытие в конце теста отдельно помечается как
`end-of-test liquidation`.

## Последствия

- устраняется базовый look-ahead;
- первый бар используется для наблюдения, а не исполнения;
- gap между close и следующим open влияет на результат;
- внутридневные стратегии потребуют более детальных данных и нового ADR.
