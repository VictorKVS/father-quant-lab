# ADR-0011 — режимная атрибуция только ретроспективна

## Статус

Принято как механический pre-S6 слой на MODELLED sample; зрелость не повышается.

## Контекст

Режимные метки можно использовать для объяснения уже полученной equity curve, но
передача той же метки стратегии превратит диагностику в новый алгоритм и потребует
новой гипотезы, плана и OOS. Кроме того, метка текущего бара известна лишь после его
закрытия.

## Решение

Интервальная доходность между соседними equity points относится к метке на закрытии
текущего бара. Атрибуция выполняется после полного независимого бэктеста.
Стратегия не получает метки. Для каждой комбинации trend/volatility считаются число
наблюдений, сложная, средняя и худшая интервальная доходность и экспозиция.

## Альтернативы и последствия

- Выбирать позицию по режиму — отклонено как новая непроверенная стратегия.
- Приписывать сделку режиму её открытия — отложено из-за различия open/close timing.
- Считать Sharpe по 3–4 наблюдениям — запрещено как ложная точность.
- Заполнять warm-up метки задним числом — запрещено как look-ahead.

Получаем проверяемую диагностическую связь. На коротком sample любые проценты не
являются сравнением режимов или доказательством эффективности.
