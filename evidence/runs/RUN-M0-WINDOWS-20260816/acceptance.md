# RUN-M0-WINDOWS-20260816 — приёмочный протокол

## Цель

Подтвердить, что новый пользователь может получить репозиторий, установить проект
на Windows, выполнить все тесты и сформировать контрольный отчёт без изменения кода.

## Среда

- ОС: Windows, PowerShell.
- Python: 3.12.10.
- pip после обновления: 26.2.1.
- Установка: `py -3.12 -m pip install -e ".[dev]"`.
- Репозиторий: `VictorKVS/father-quant-lab`, ветка `main`.
- Проверяемый коммит: `ea286eb`.

## Фактическое выполнение

1. Репозиторий обновлён fast-forward до `ea286eb`.
2. Editable package `father-quant-lab==0.1.0` успешно собран и установлен.
3. Установлены pytest и ruff.
4. `py -3.12 -m unittest discover -s tests -v` выполнил 13 тестов.
5. Все 13 тестов завершились `OK`; ошибок и пропусков нет.
6. Команда `run-controls` создала `reports/generated/m0-controls.json`.
7. JSON содержит четыре стратегии `BOT-CTRL-000..003`, полные equity curves,
   исполнения, метрики, конфигурацию риска, seed и происхождение данных.
8. Поля `mode=backtest_only` и `live_orders_forbidden=true` подтверждены.

## Обнаруженная и устранённая проблема среды

Первый запуск выполнялся до установки пакета и завершился
`No module named father_quant_lab`. Установка проекта в editable-режиме устранила
причину. Предыдущая попытка на Python 3.10 также была некорректна: проект требует
Python 3.12 или новее.

## Решение тестировщика

`ACCEPTED` для этапа M0/S0 как воспроизводимого синтетического контрольного
baseline. Протокол не подтверждает прибыльность, качество реальных данных,
готовность терминала или допустимость торговли реальными деньгами.
