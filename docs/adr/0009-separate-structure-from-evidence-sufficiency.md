# ADR-0009 — структура плана не равна достаточности выборки

## Статус

Принято для M0/S4 как блокирующая поправка; прежний immutable run сохраняется.

## Контекст

`FQL-S4-GATE-004` правильно подтвердил SHA, порядок и непересечение трёх участков,
но sample содержит лишь 4 бара на участок при `long_window=5`. Такой участок не
может самостоятельно прогреть стратегию. Статус структурной валидности нельзя
трактовать как готовность к оценке.

## Решение

Добавить независимый `FQL-S4-GATE-005`. Он извлекает максимальный положительный
параметр `*_window`, требует независимый warm-up на каждом участке и прибавляет
предварительно зарегистрированное минимальное число оцениваемых баров.

Для M0 используется 20 оцениваемых баров после warm-up. Это только механический
smoke minimum, выбранный для выявления тривиально коротких участков. Он не является
оценкой statistical power, репрезентативности режима или достаточного числа сделок.

## Альтернативы и последствия

- Переписать прежний result — отклонено: нарушает неизменяемость доказательств.
- Передавать warm-up из TRAIN в OOS — отклонено для этого gate: усложняет границу и
  может скрыть зависимость участков.
- Объявить 20 баров статистическим минимумом — запрещено как ложная точность.
- Сразу выбрать 252/1000 баров — отложено до определения частоты, режима и power
  analysis на допущенных данных.

Результат прошлого gate остаётся `VALID_MODELLED_ONLY`, но новый gate блокирует
оценку как `BLOCKED_INSUFFICIENT_BARS`.
