# ADR-0010 — режимные метки являются диагностикой, а не истиной рынка

## Статус

Принято как механический pre-S6 прототип на MODELLED sample. Торговые разрешения
и зрелость не изменяются.

## Контекст

Метрики робота нужно позднее разбирать по рыночным режимам, однако разметка,
использующая будущую цену или пороги, подобранные по прибыли, создаст look-ahead.
Также один алгоритм не может доказать существование «истинного» режима.

## Решение

Первая версия использует только текущий закрытый бар и заданное число предшествующих
баров. Trend определяется накопленной доходностью окна относительно фиксированного
порога, volatility — RMS логарифмических доходностей относительно фиксированного
порога. Каждая метка содержит `available_to_system_at`, равный времени закрытого
бара. До полного окна метка отсутствует.

## Альтернативы и последствия

- Будущая доходность для разметки отклонена как look-ahead.
- HMM/k-means отложены: требуют fit-периода, версии модели и отдельного OOS gate.
- ATR/ADX отложены до проверки независимой реализации индикаторов.
- Порог, оптимизированный по PnL, запрещён.

Получаем объяснимый причинный контракт. Пороги 20/50 bps и окно 5 — только
MODELLED fixtures; они не являются рекомендацией для EUR/USD.
