## CRITIQUE

Главный риск первоначальной матрицы — смешать общую глубину истории поставщика с
доказанной доступностью конкретных EUR/USD и DEM/USD рядов. Поэтому LSEG не получил
допуск, несмотря на заявленную историю pricing с 1975 года: exact series, venue,
timestamp semantics, license и sample остаются `PENDING`.

Слово `BLOCKED` не означает, что поставщик плох. Оно означает, что имеющихся
доказательств недостаточно для нашего конкретного M0 и публичного воспроизведения.

## DECISION → LESSON

Вердикт по самому gate: `ACCEPTED`. Вердикт по выбору поставщика: `BLOCKED`.

Доказано: критические неизвестные поля останавливают процесс; ECB reference не может
пройти tradable gate; история после 1992 блокируется; полностью проверенный
синтетический контракт способен получить только `ELIGIBLE_FOR_PILOT`.

Не доказано: фактическое качество samples, точные договорные цены, полнота DEM/USD,
долгосрочная стабильность API и допустимость публичного хранения коммерческих данных.

Следующий шаг: подготовить vendor due-diligence questionnaire и минимальный sample
contract для LSEG, OANDA и Dukascopy без покупки и без передачи credentials.
