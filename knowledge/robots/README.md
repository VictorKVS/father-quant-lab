# Robot registry

Каждый робот получает каталог `BOT-...` со следующими файлами:

- `passport.yaml` — назначение, владелец, maturity и разрешённые режимы;
- `hypothesis.md` — механизм, предпосылки и критерии опровержения;
- `parameters.yaml` — зарегистрированные параметры и допустимые диапазоны;
- `evidence.md` — книги, данные, тесты и контрдоказательства;
- `results/` — ссылки на неизменяемые отчёты запусков.

Торговый робот не может изменять собственный maturity, risk policy или результаты.
Решение принимает `AGT-COUNCIL-408` на основании независимых проверок.
