# ADR-0004: справочный курс не является торговым баром

- Статус: accepted
- Дата: 2026-08-16

## Контекст

Официальный ECB reference rate полезен для макроанализа и проверки происхождения,
но не содержит bid/ask, high/low, объём, микроструктуру и доказанное время исполнения.

## Решение

Хранить справочные значения в отдельной модели `ReferenceObservation`. Запретить их
автоматическое преобразование в `Bar` и прямую передачу в `BacktestEngine`.

## Последствия

- официальный источник не превращается в ложную торговую истину;
- S2 может проверить ingestion, raw evidence и provenance до выбора OHLC-поставщика;
- event studies потребуют отдельной модели publication/availability time;
- для бэктеста остаётся нужен лицензированный или явно разрешённый OHLC/bid-ask ряд.
