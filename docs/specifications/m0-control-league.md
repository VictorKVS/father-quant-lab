# ТЗ: M0 Control League

## 1. Назначение

Создать минимальную воспроизводимую установку, относительно которой будут
оцениваться все будущие торговые, ML- и AI-роботы. Установка не прогнозирует рынок
и не подключается к брокеру. Она проверяет корректность данных, временную причинность,
исполнение, риск, метрики и отчётность.

## 2. Граница системы

Вход: один упорядоченный ряд OHLC одного инструмента в UTC.

Выход: неизменяемый JSON-отчёт по четырём контрольным роботам:

- `BOT-CTRL-000` — NO-TRADE;
- `BOT-CTRL-001` — RANDOM с фиксированным seed;
- `BOT-CTRL-002` — BUY-HOLD;
- `BOT-CTRL-003` — PERIODIC REBALANCE.

Реальные заявки, API-ключи, кредитное плечо, short и оптимизация параметров не входят
в M0.

## 3. Функциональные требования

| ID | Требование | Проверка |
|---|---|---|
| FQL-FR-001 | CSV содержит точные поля timestamp, instrument, open, high, low, close | `test_csv_schema_is_strict` |
| FQL-FR-002 | Временные метки timezone-aware, уникальны и строго возрастают | `test_data.py` |
| FQL-FR-003 | Решение после закрытия бара исполняется не ранее открытия следующего | `test_signal_is_executed_on_next_bar_not_current_close` |
| FQL-FR-004 | Исполнение учитывает spread, slippage и commission | `test_costs_reduce_buy_hold_result` |
| FQL-FR-005 | Один risk engine запрещает short и leverage всем стратегиям | `test_risk_policy_rejects_leverage_and_short_targets` |
| FQL-FR-006 | Drawdown limit активирует kill switch и запрещает повторный вход | `test_kill_switch_liquidates_and_blocks_reentry` |
| FQL-FR-007 | RANDOM полностью повторяется при одинаковом seed | `test_seeded_random_strategy_is_reproducible` |
| FQL-FR-008 | Отчёт сериализуется и содержит `live_orders_forbidden=true` | `test_reporting.py` |

## 4. Нефункциональные требования

- Python 3.12+;
- только стандартная библиотека в runtime;
- детерминированный результат;
- отсутствие сетевого доступа во время теста;
- стратегия не изменяет данные, риск или модель исполнения;
- внешние движки позже обязаны совпасть с эталоном на golden fixtures.

## 5. Критерий приёмки

M0 Control League принимается, если:

1. все автоматические тесты зелёные;
2. CLI одной командой формирует JSON;
3. повторный запуск с тем же seed даёт идентичный файл;
4. NO-TRADE не создаёт fills;
5. BUY-HOLD не использует цену до момента доступности;
6. отчёт содержит торговые издержки через итоговые fills и equity curve;
7. ручной анализ тестировщика не выявил блокирующей неоднозначности.
