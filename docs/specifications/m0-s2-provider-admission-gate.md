# FQL-S2-GATE-002 — допуск поставщика торговых FX-данных

## Идея и гипотеза

Название известного поставщика или бесплатный API не являются доказательством
пригодности данных. До написания адаптера кандидат должен пройти одинаковый gate.

Гипотеза: машиночитаемый реестр и fail-closed алгоритм не позволят начать бэктест
на данных с неизвестной лицензией, неполной историей или неясной ценовой семантикой.

## Обязательные условия допуска

1. Первичные HTTPS-доказательства характеристик поставщика.
2. Проверенная лицензия и право локального хранения исследовательской копии.
3. Bid/ask, trades либо раздельные bid/ask OHLC; reference/mid alone недостаточно.
4. Подтверждённая история с 1992 года для заявленного M0 либо формально ограниченный
   подпериод, который не выдаётся за полный M0.
5. Точная семантика timestamp, timezone, interval boundary и complete/incomplete.
6. Политика исправлений, revisions и способ version pinning.
7. Подтверждение EUR/USD и исторической связки DEM/USD без автоматического склеивания.
8. Raw preservation, SHA-256, source attribution и воспроизводимый parser.

## Рассмотренные кандидаты

| Кандидат | Подтверждено | Блокирует допуск |
|---|---|---|
| ECB EXR | официальный reference, reuse | не торговая цена; EUR только с 1999 |
| OANDA v20 | bid/ask/mid candles; история с 2005 | нет 1992–2004; договорные права не проверены |
| Dukascopy Export | tick–monthly export | earliest date, точная схема и reuse rights не приняты |
| Tick Data | bid/ask ticks и bid OHLC с 01.05.2008 | нет ранней истории; цена и лицензия по договору |
| LSEG | FX pricing заявлен с 1975; Tick History содержит quotes/trades/depth | точные ряды, venue, стоимость и лицензия требуют подтверждения |
| 360T | derived bid/ask с марта 2024 | слишком короткая история; non-executable feed |

Полные факты и ссылки находятся в
`configs/data-providers/fx_provider_registry.json`. Отсутствующее значение означает
`PENDING`, а не отрицательный факт.

## Альтернативы

- **Скачать первый доступный CSV.** Отклонено: неизвестные права и временная семантика.
- **Использовать только mid.** Отклонено как база исполнения; допустимо лишь для
  отдельного reference/factor исследования.
- **Склеить несколько поставщиков без маркировки.** Отклонено: смена источника может
  создать ложный режим и искусственную доходность.
- **Сразу купить самый дорогой набор.** Отклонено до sample-validation и определения
  минимально достаточного подпериода.

## Решение ролей

- Аналитик определяет исследовательский период и допустимые разрывы.
- Data Engineer проверяет схему, timestamp и raw lineage.
- Архитектор запрещает смешение reference, broker и venue feeds без regime marker.
- Юридический/закупочный reviewer подтверждает storage и redistribution rights.
- Тестировщик выполняет sample probe и negative cases.
- Риск-контролёр не разрешает live credentials и торговые заявки.
- Критик ищет selection bias поставщика и survivorship/revision artifacts.

## Критерий приёмки gate

- реестр проходит schema/uniqueness проверки;
- каждое неизвестное критическое поле блокирует кандидата;
- reference rate не может пройти tradable gate;
- кандидат после 1992 блокируется для полного M0;
- существует положительный синтетический тест полностью проверенного контракта;
- текущий реестр честно возвращает `BLOCKED`, пока ни один кандидат не проверен.

## Граница

`ELIGIBLE_FOR_PILOT` разрешает только небольшой offline ingestion sample. Он не
разрешает покупку, передачу ключей, полный download, paper/live или торговлю.
